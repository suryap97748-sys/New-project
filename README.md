# Surya E-Mart - Java Online Shopping Website

Technology: Java 17, Spring Boot, Spring Data JPA, PostgreSQL, HTML/CSS/JavaScript.

## Run locally
1. Install Java 17, Maven and PostgreSQL.
2. Create a PostgreSQL database named `suryaemart`.
3. In `application.properties`, set your PostgreSQL password OR set DB_USERNAME/DB_PASSWORD environment variables.
4. Run: `mvn spring-boot:run`
5. Open: http://localhost:8080

## Cloud
Set DATABASE_URL, DB_USERNAME and DB_PASSWORD as environment variables on your cloud service. Do not put passwords in GitHub.
